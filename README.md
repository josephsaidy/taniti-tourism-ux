# Taniti Tourism Website — UX Prototype

## Overview
This project was developed by Joseph Saidy for WGU's D479 User Experience Design course. The objective is to redesign the fictional island of Taniti's tourism website to improve navigation, accessibility, and the overall visitor experience.

## Features
- Responsive, mobile-friendly website
- Activities and attractions information
- Accommodation options
- Transportation information
- Frequently asked questions
- Interactive trip-planning functionality

## Technologies
- HTML5
- CSS3
- JavaScript
- GitHub Pages for hosting

## UX Design Process
1. Requirements analysis and user research
2. User persona development
3. Sitemap and low-fidelity wireframes
4. Guerrilla usability testing
5. Design revisions
6. Interactive prototype development

## How to Run
Open `index.html` in a web browser or visit the published GitHub Pages website.

## Project Status
Prototype development and usability evaluation in progress.
